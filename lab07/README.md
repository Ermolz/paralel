# Лабораторная 7

Разделы 3.1–3.3 учебника: передача Java-объектов и их массивов через сериализацию.
Все шесть процедур из разделов собраны в четыре самостоятельные программы.
Запуск выполняется на 4 MPI-процессах, источник данных — ранг 0.

Run:

```bash
cd ~/paralel
./lab lab07
```

Отдельный пример: `./lab lab07 objects`. Только сборка: `./lab lab07 build`.

| Java-файл | Команда | Процедуры |
| --- | --- | --- |
| `TestSendObject.java` | `object` | `sendObject` и `recvObject`: передача объекта `Student`. |
| `TestSendObjects.java` | `objects` | `sendObjects` и `recvObjects`: передача массива объектов через `iSend`. |
| `TestBcastObject.java` | `bcast` | `bcastObject`: коллективная рассылка объекта `Student`. |
| `TestBcastObjectArray.java` | `bcastarray` | `bcastObjectArray`: коллективная рассылка массива объектов. |

Объект `Student` реализует `Serializable`. В массивах передаются строки,
целое число и вложенный массив `int[]`. При обычном приёме размер байтового
сообщения определяется через `probe` и `getCount(MPI.BYTE)`.
При коллективной рассылке сначала передаётся длина, затем сами байты.

В примере `recvObjects` исправлен тип параметра `tag`: `int` вместо `t`.
`sendObjects` возвращает `Request`; после запуска отправок программа вызывает
`waitFor` для каждого запроса до `MPI.Finalize`. Используется прямой байтовый
буфер. Потоки сериализации закрываются, ошибки передаются вызывающему коду.

Все четыре программы собраны и проверены ручными запусками на 4 процессах.
Вручную сверены поля восстановленных объектов и содержимое массивов на каждом
получателе. Автоматические тесты не использовались. Фактический вывод сохранён
в `results/` и комментариях Java-файлов с подписями `Run:` и `Terminal output:`.

Для сдачи нужны только четыре `.java` из
`src/main/java/com/mathpar/NAUKMA/stud2026/GR03/yermolovych/`.
