# Лабораторная 8

Разделы 4.1–4.4 учебника. Используются настоящие классы Mathpar:
`MatrixD`, `MatrixS`, `VectorS`, `NumberZ`, `Ring` и `MPITransport`.
Библиотека и её зависимости находятся в общей папке `lib/mathpar/`.

Run:

```bash
cd ~/paralel
./lab lab08
```

| Java-файл | Команда | Процессов по умолчанию | Задача |
| --- | --- | ---: | --- |
| `MatrixMul4.java` | `mat4` | 4 | Умножение матриц 4 × 4; каждый процесс вычисляет один блок результата. |
| `MatrixMul8.java` | `mat8` | 8 | Умножение матриц 8 × 8; восемь блочных произведений складываются попарно. |
| `MultiplyMatrixToVector.java` | `matvec` | 4 | Умножение матрицы 16 × 16 на вектор с распределением строк. |
| `MultiplyVectorToScalar.java` | `scale` | 4 | Умножение вектора из 8 элементов на число 5. |

Отдельный пример: `./lab lab08 mat8`. Только сборка: `./lab lab08 build`.
Для `matvec` разрешено 1–16 процессов, для `scale` — 1–8.
Проверенные запуски с остатком: `./lab lab08 matvec 3` и `./lab lab08 scale 3`.

Входные данные фиксированы для повторяемой ручной проверки. При нумерации
с нуля в `MatrixMul8` результат равен
`C[i][j] = 204 + 288*i + (36 + 64*i)*j`.
В примере матрицы и вектора `result[i] = 1496 + 136*i`.
Результат умножения вектора на 5: `[-15, -10, -5, 0, 5, 10, 15, 20]`.

Исправлены опечатки книги в параметре `b`, импортах и типе массива `MatrixD[]`,
а также название транспорта `MPITransport`. При распределении строк матрицы
процесс j получает строки начиная с `(j - 1) * count`; нулевой процесс
обрабатывает оставшиеся строки в конце. Это устраняет пропуск первых строк
и повторную обработку последних строк из книжного примера.

Все четыре программы собраны и проверены вручную на указанном числе процессов.
Оба примера с векторами дополнительно проверены на 3 процессах.
Автоматические тесты не использовались. Реальный вывод сохранён в `results/`
и комментариях Java-файлов с подписями `Run:` и `Terminal output:`.
Журнал первоначальной ошибки упаковки библиотеки сохранён отдельно;
недостающие ресурсы добавлены, повторные запуски успешны.

`src/main/java/com/mathpar/NAUKMA/stud2026/GR03/yermolovych/`.
