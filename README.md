# Лабораторные по параллельному программированию

Yermolovych, группа 03, 2026.

- `Labs.pdf` — задания лабораторных 1–11.
- `MPI_Java_Mathpar_2025.pdf` — учебник, 274 страницы.
- `lab01/` — первая лабораторная: исходники, запуск и сохранённое исследование.
- `lab02/` — коммуникаторы для чётных рангов и матричной топологии.
- `lab03/` — рассылка массивов через `send/recv`, `iSend/recv` и `iSend/iRecv`.
- `lab04/` — проверка сообщений, ожидание запросов, группы и блокирующий/неблокирующий обмен.
- `lab05/` — коллективные операции: `bcast`, `gather`, `gatherv`, `scatter`, `scatterv`, `allGather`, `allGatherv`, `allToAll`, `allToAllv`.
- `lab06/` — редукции `reduce`, `allReduce`, `reduceScatter`, `scan` и синхронизация `barrier`.
- `lab07/` — сериализация, передача объектов и их массивов, коллективная рассылка объектов.
- `lab08/` — блочное умножение матриц на 4 и 8 процессах, матрицы на вектор и вектора на число.
- `lab09/` — решение случайной системы методом Гаусса—Жордана на сетке процессов с коммуникаторами строк и столбцов.
- `lab10/` — полный выбор ведущего элемента, два способа обмена максимумами и сравнение времени с диагональным методом.
- `lab11/` — сравнение невязки методов на 64 процессах и времени на четырёх физических ядрах; матрица 2048×2048.
- `lib/`, `scripts/`, `pom.xml`, `hostfile` — общие зависимости и настройки.
- `lib/mathpar/` — локальная библиотека Mathpar и её зависимости для лабораторной 8.
- `logs/` — журналы установки общего OpenMPI.

PDF хранятся локально и не включаются в Git. Оба файла проверены и скопированы без изменений. Текст книги извлекается со всех
274 страниц, просмотренные страницы читаются нормально. В примерах встречаются
опечатки: например, на странице 67 параметр `D` используется далее как `b`.

Личные Java-файлы находятся внутри каждой лабораторной в
`src/main/java/com/mathpar/NAUKMA/stud2026/GR03/yermolovych/`.

Запуск в Ubuntu / WSL:

```bash
cd ~/paralel
./lab lab01 1
./lab lab01 results
./lab lab02
./lab lab03
./lab lab04
./lab lab05
./lab lab06
./lab lab07
./lab lab08
./lab lab09
./lab lab10
./lab lab11
```

Прежние команды `./lab 1` и `./lab results` тоже работают: по умолчанию выбирается `lab01`.
Все команды первой лабораторной описаны в `lab01/README.md`.
Для сборки через Maven из корня: `mvn -o package`;
для другой лабораторной с Java-исходниками: `mvn -o -Dlab.directory=lab02 package`.

Преподавателю сдаём только `.java`: в каждом файле нужны комментарий с командой
запуска и фактический вывод терминала.
