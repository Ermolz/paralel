# Лабораторная 6

Разделы 2.10–2.14 учебника: четыре примера редукции и демонстрация барьера.
Запуски рассчитаны на 4 MPI-процесса, как в примерах книги.

Run:

```bash
cd ~/paralel
./lab lab06
```

Отдельный пример: `./lab lab06 reducescatter`. Только сборка: `./lab lab06 build`.

| Java-файл | Команда | Действие |
| --- | --- | --- |
| `TestReduce.java` | `reduce` | Поэлементная сумма массивов на ранге 0. |
| `TestAllReduce.java` | `allreduce` | Поэлементное произведение массивов на всех рангах. |
| `TestReduceScatter.java` | `reducescatter` | Поэлементная сумма с распределением блоков длиной 1, 2, 3 и 4. |
| `TestScan.java` | `scan` | На ранге r — сумма массивов рангов от 0 до r включительно. |
| `TestBarrier.java` | `barrier` | Ранг 3 задерживается на 500 мс, остальные ждут его на барьере. |

В `reduceScatter` исправлен вывод только на нулевом ранге из книги:
каждый процесс печатает свой блок. Приёмный массив содержит ровно
получаемое число элементов, без лишних нулей.

В примере `barrier` первый барьер синхронизирует начало, второй показывает
ожидание задержанного процесса. Выход из барьера означает, что все процессы
вошли в него; одновременное продолжение выполнения и порядок строк вывода
не гарантируются.

Все пять примеров собраны и проверены ручными запусками на 4 процессах.
Вручную сверены суммы, произведения, префиксные суммы, распределение блоков
и время ожидания барьера. Автоматические тесты не использовались.
Фактический вывод находится в `results/` и комментариях Java-файлов
с подписями `Run:` и `Terminal output:`. Дата измерения барьера сохранена
в первой строке `results/TestBarrier.txt`.

`src/main/java/com/mathpar/NAUKMA/stud2026/GR03/yermolovych/`.
