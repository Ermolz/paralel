# Лабораторная 9

Решение системы `A * X = B` методом Гаусса—Жордана без выбора ведущего
элемента. Все ведущие элементы берутся с диагонали.

Run:

```bash
cd ~/paralel
./lab lab09
```

Параметры: `./lab lab09 [processes] [N] [seed]`.
По умолчанию: 4 процесса, `N = 4`, `seed = 2026`.
Число процессов должно равняться `n * n`, а `N` — делиться на `n`.
Например: `./lab lab09 9 6 42`.

Матрица `[A | B]` размера `N x (N + 1)` заполняется случайными значениями
`double` от 1 до 100. Одинаковый `seed` воспроизводит одну и ту же матрицу.
Каждый процесс получает блок `k x k`, где `k = N / n`; последний блок
в каждой строке имеет размер `k x (k + 1)` и содержит часть `B`.

Через `split` создаются `n` коммуникаторов строк и `n` коммуникаторов столбцов.
На каждом шаге ведущий элемент передаётся по его строке процессов, затем
по столбцам. Коэффициенты исключения рассылаются по строкам, а части
нормированной ведущей строки — по столбцам. Каждый процесс обновляет свой блок.
В конце последний столбец процессов собирает `X` и передаёт его процессу 0.

Исходная матрица сохраняется на процессе 0 для вычисления
`P = A * X - B` и `max(abs(P[i]))`. При `N <= 12` печатаются также
матрица, решение и весь вектор невязки. Нулевой, слишком малый
(`abs(pivot) <= 1e-12`) или нечисловой ведущий элемент останавливает расчёт;
перестановки строк и столбцов в этой лабораторной не выполняются.

Ручная проверка выполнена 2026-09-22, без автоматических тестов:

| Процессов | N | seed | max(abs(P[i])) |
| ---: | ---: | ---: | ---: |
| 1 | 4 | 2026 | 7.105427357601e-15 |
| 4 | 4 | 2026 | 7.105427357601e-15 |
| 9 | 6 | 42 | 2.273736754432e-13 |
| 16 | 8 | 2026 | 2.984279490192e-13 |
| 4 | 2 | 2026 | 2.842170943040e-14 |

Решения на 1 и 4 процессах совпали. Подстановка напечатанных значений
для `N = 4` отдельно проверена с десятичной арифметикой повышенной точности.
Неквадратное число процессов и несовместимый размер матрицы отклоняются
без зависания. Это проверка правильности, измерения времени не проводились.

Вывод запусков сохранён в `results/`. В журнале запуска с `N = 2` сохранено
предупреждение JVM о занятом файле служебной статистики; расчёт завершился успешно.
