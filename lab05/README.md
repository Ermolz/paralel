# Лабораторная 5

Разделы 2.1–2.9.1 учебника: девять примеров коллективного обмена.

Run:

```bash
cd ~/paralel
./lab lab05
```

Отдельный пример: `./lab lab05 scatterv`. Только сборка: `./lab lab05 build`.
Последним аргументом можно указать число процессов, например `./lab lab05 gather 3`.

| Java-файл | Команда | Процессов по умолчанию | Действие |
| --- | --- | ---: | --- |
| `TestBcast.java` | `bcast` | 4 | Передаёт массив ранга 0 всем процессам. |
| `TestGather.java` | `gather` | 4 | Собирает блоки по 5 элементов на последнем ранге. |
| `TestGatherv.java` | `gatherv` | 2 | Собирает блоки по заданным размерам и смещениям на последнем ранге. |
| `TestScatter.java` | `scatter` | 2 | Распределяет массив ранга 0 по 3 элемента каждому процессу. |
| `TestScatterv.java` | `scatterv` | 4 | Распределяет блоки по 4 элемента с заданными смещениями. |
| `TestAllGather.java` | `allgather` | 4 | Собирает блоки по 2 элемента на каждом процессе. |
| `TestAllGatherv.java` | `allgatherv` | 2 | Собирает блоки на каждом процессе в обратном порядке рангов. |
| `TestAllToAll.java` | `alltoall` | 4 | Каждый процесс отправляет каждому по одному элементу. |
| `TestAllToAllv.java` | `alltoallv` | 4 | Такой же обмен с обратным порядком отправителей в приёмном массиве. |

В вариантах `v` размеры и смещения задаются массивами; равные размеры блоков
сохранены из примеров книги. Смещения измеряются в элементах `MPI.INT`.
Массивы размеров и смещений соответствуют числу процессов.

Исправлены две неточности книги: в `scatter` исходный массив содержит ровно
по 3 элемента на процесс; в `scatterv` ранг 1 получает `[4, 5, 6, 7]`,
а ранг 2 — `[8, 9, 10, 11]`.

Все девять примеров собраны и проверены ручными запусками с числом процессов
из таблицы. Просмотрены исходные и полученные массивы, ранги и порядок блоков.
Автоматические тесты не использовались. Фактический вывод сохранён в `results/`
и в комментариях Java-файлов с подписями `Run:` и `Terminal output:`.

Для сдачи нужны только девять `.java` из
`src/main/java/com/mathpar/NAUKMA/stud2026/GR03/yermolovych/`.
