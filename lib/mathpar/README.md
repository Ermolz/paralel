# Локальная библиотека Mathpar

`mathpar-core-9.0-local.jar` собран из исходников Mathpar 9.0,
снимок `86509d19d193f8f3e26df906df539394ab509bd7`.
Включены 209 классов, необходимых для матриц, чисел, векторов и транспорта MPI,
и два обязательных ресурса конфигурации. Исходные Java-классы не изменялись.
Их тексты сохранены в `mathpar-core-9.0-local-sources.zip` вместе с ресурсами.

Локальные зависимости: Log4j API/Core 2.24.3, Commons IO 2.18.0,
JSch 0.1.55, Jackson Annotations 2.18.2, Validation API 2.0.1.Final
и Javatuples 1.2. Оригинальные уведомления о лицензиях находятся внутри JAR.
Контрольные суммы загруженных зависимостей проверены перед сборкой.

Maven подключает библиотеку профилем `mathpar`, который автоматически
активируется при `-Dlab.directory=lab08`. Локальные артефакты находятся
в `lib/maven/`; копии подготовлены в кэше Maven текущей WSL.
Запуск лабораторной использует `lib/mpi.jar` и `lib/mathpar/*`.
Интернет для текущих сборки и запуска не требуется.
